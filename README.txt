JAY KOSHAL — AndroidIDE Project
================================

1. Install AndroidIDE on your Android phone.
2. Extract this ZIP.
3. Open/import the project folder "JAY_KOSHAL_AndroidIDE".
4. Let Gradle sync/download dependencies.
5. Choose Build > Assemble Debug APK (wording may vary).
6. Install the generated APK.

The app loads the complete JAY KOSHAL HTML app offline from app/src/main/assets/index.html.
Application ID: com.jaykoshal.app
Version: 1.0
